## Contributing

Thanks for the interest. This repository is a portfolio project; contributions are welcome as small, well-scoped improvements.

### Guidelines

- **No secrets**: never include `.env`, credential files, tokens, or project-specific identifiers in commits.
- **No course material**: do not submit rubric/instruction content from any educational program.
- **Keep tests offline**: unit tests should not call external APIs.

### Development

```bash
pip install -e ".[dev]"
pytest
```
